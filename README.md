Minha dieta (PWA)
Instalar no iPhone

    Abra o endereço no Safari, toque em Compartilhar > "Adicionar à Tela de Início".
    Instale o app gratuito ntfy (App Store).
    Abra o app pelo ícone da Tela de Início > Ajustes > Lembretes. Copie o tópico.
    No ntfy: "+" > servidor ntfy.sh > cole o tópico. Permita notificações.
    No app da dieta: "Enviar notificação de teste".

Importante: o app instalado na Tela de Início tem armazenamento separado do Safari. Configure sempre pelo ícone instalado.
