Minha dieta (PWA)
Publicar no GitHub Pages (grátis)
Crie um repositório público no GitHub (ex.: `dieta`).
Envie todos os arquivos desta pasta para a raiz do repositório.
Settings > Pages > Source: "Deploy from a branch" > branch `main`, pasta `/ (root)` > Save.
Em ~1 minuto o app fica em `https://SEU-USUARIO.github.io/dieta/`.
Instalar no iPhone
Abra o endereço no Safari, toque em Compartilhar > "Adicionar à Tela de Início".
Instale o app gratuito ntfy (App Store).
Abra o app pelo ícone da Tela de Início > Ajustes > Lembretes. Copie o tópico.
No ntfy: "+" > servidor `ntfy.sh` > cole o tópico. Permita notificações.
No app da dieta: "Enviar notificação de teste".
Importante: o app instalado na Tela de Início tem armazenamento separado do Safari.
Configure sempre pelo ícone instalado.
